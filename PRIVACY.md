# Privacy Policy — FoxESS Export Control

**Last updated: 6 September 2026**

FoxESS Export Control is an independent Home Assistant custom integration maintained by **MrHC1983**.

The integration stores its FoxESS API key and device serial number in Home Assistant's integration configuration. It communicates directly with the FoxESS Cloud API to read and set the configured device's export limit.

It does **not** collect personal information for the developer, use analytics, sell/share data, send telemetry to the developer, or operate a remote user-data server.

The FoxESS API key is sensitive. Never publish it in GitHub, screenshots, logs or issue reports. If exposed, revoke/regenerate it through FoxESS.

Not affiliated with or endorsed by FoxESS, FoxESS Cloud, Home Assistant, electricity retailers or electricity distributors.
